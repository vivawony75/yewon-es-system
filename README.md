# ✍️ [예원 전자서명 시스템] 사용 가이드

본 웹 애플리케이션은 관리자가 업로드한 양식 파일(PDF)에 지정된 선생님들의 손글씨 전자서명을 실시간으로 날인하고, 서명이 완료된 최종 PDF 문서를 생성 및 다운로드할 수 있는 경량 전자서명 웹앱입니다.

---

## 📁 1. 설치 및 폴더 위치
- **위치**: 바탕화면 `[예원전자서명시스템]` 폴더
- **실행 방법**: 폴더 내 `시작하기.bat` 파일을 더블클릭하거나, `index.html` 파일을 크롬/엣지 등의 웹 브라우저로 엽니다.

---

## 👥 2. 사용자(선생님) 서명 절차
1. **접속 및 본인 확인**:
   - 웹앱 링크로 접속하면 이름(성명) 입력창이 나타납니다.
   - 관리자가 등록한 양식 명단의 성명과 일치할 경우:
     👉 **“000 선생님 반갑습니다”** 환영 메시지가 표시되며 서명 대상 문서 미리보기와 서명란이 제시됩니다.
   - 명단에 없는 성명을 입력한 경우:
     👉 **“다시 입력해 주세요”** 안내 메시지가 표시되어 재입력을 유도합니다.
2. **문서 확인 및 서명**:
   - 화면에 표시된 양식 문서를 스크롤하여 확인합니다.
   - 하단 **[서명란]**에 마우스나 모바일/태블릿 터치펜, 손가락으로 서명합니다.
3. **서명 제출**:
   - **[다시 하기]**: 서명을 지우고 처음부터 다시 서명합니다.
   - **[제출]**: 서명이 최종 양식 PDF에 자동 합성 날인되며, 완료 화면에서 본인의 서명 완료본 PDF를 즉시 확인 및 다운로드할 수 있습니다.

### 📌 관리자 3대 핵심 메뉴

#### ① [시작] 메뉴
- **양식 파일 업로드**:
  - 서명받을 서약서, 동의서 등의 PDF 양식 파일을 드래그 앤 드롭하거나 파일 선택으로 업로드합니다.
  - 시스템에 기본 표준 서약서 템플릿이 내장되어 있어 별도 파일 없이도 즉시 테스트할 수 있습니다.
- **서명 대상자 명단 관리**:
  - 서명할 선생님들의 성명을 추가하거나 삭제합니다. (쉼표나 줄바꿈으로 일괄 추가 가능)
- **서명 위치 설정 (PDF 좌표)**:
  - 서명 이미지가 날인될 페이지 번호, X/Y 좌표 및 크기를 미세 조정할 수 있습니다. (기본 프리셋 제공)
- **[설정 저장하기]**: 변경한 설정을 저장합니다.

#### ② [진행] 메뉴
- **실시간 통계**: 총 대상자 수, 서명 완료 인원, 서명 대기 인원, 실시간 서명률(%) 확인.
- **실시간 서명 현황 게시판**:
  - 선생님별 서명 상태 (완료 / 대기 중).
  - 서명 일시 및 실제 손글씨 서명 썸네일 노출 (썸네일 클릭 시 고화질 원본 확대 확인).
  - 특정 선생님 전용 서명 링크 복사 및 서명 초기화 기능 제공.
- **[🔗 사용자 서명 링크 복사]**: 선생님들께 전달할 링크 주소를 원클릭으로 클립보드에 복사합니다.

#### ③ [완료] 메뉴
- **개별 PDF 다운로드**: 서명이 완료된 선생님의 문서를 `[서명완료]_{선생님성명}_{양식명}.pdf` 형식으로 개별 다운로드합니다.
- **문서 미리보기**: 브라우저 내에서 서명이 합성된 최종 문서를 즉시 열람합니다.
- **📦 전체 완료 문서 일괄 다운로드 (ZIP)**: 모든 서명 완료 문서를 하나의 압축 파일(ZIP)로 묶어 한 번에 내려받습니다.

## 🛠️ 주요 파일 구성
| 파일명 | 역할 설명 |
| :--- | :--- |
| `index.html` | 메인 사용자/관리자 통합 웹 화면 |
| `styles.css` | 모바일/PC 반응형 모던 디자인 스타일시트 |
| `app.js` | 서명 캔버스, 실시간 상태 관리, PDF 합성 및 IndexedDB 로직 |
| `config.js` | 관리자 계정(ID/PW) 및 기본 설정값 (안티그래비티로 수정 가능) |
| `시작하기.bat` | 더블클릭 시 브라우저에서 웹앱을 바로 실행하는 배치 파일 |
| `README.md` | 시스템 상세 사용 설명서 |
